## What is it?
This is a silly mod that I made first starting to mod the game. Completely unintentionally, I found out that Arthur can be set on fire using script hook, but only retains voice lines and animation, no fire assets. If you want to stumble around the camp hollering, this mod is for you!

## Requirements:

**Script hook is required to use this mod**
